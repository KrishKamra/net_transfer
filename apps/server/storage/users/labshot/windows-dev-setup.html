0. Prerequisites

Start here ▼

Verify winget is available

Open Windows Terminal or PowerShell and run:

winget --versionCopy
If the command is not recognized, open the Microsoft Store and install or update App Installer.

Run terminal as Administrator (recommended)

Right-click Windows Terminal / PowerShell → Run as administrator. This avoids permission issues with machine-wide installs.

1. Install All Tools (One Shot)

Fastest ▼

Install VS Code, Git, Python & Node.js LTS

Copy and paste this single command. It installs the recommended stable packages:

winget install -e --id Microsoft.VisualStudioCode --accept-package-agreements --accept-source-agreements && winget install -e --id Git.Git --source winget --accept-package-agreements --accept-source-agreements && winget install -e --id Python.Python.3.12 --accept-package-agreements --accept-source-agreements && winget install -e --id OpenJS.NodeJS.LTS --accept-package-agreements --accept-source-agreementsCopy
After the command finishes, close and reopen the terminal so PATH updates take effect.

3. Configure Git

Required ▼

Set your name and email

Replace the placeholders with your real name and email (use the email linked to your GitHub account if you plan to push there).

git config --global user.name "Your Name" git config --global user.email "you@example.com"Copy

Useful defaults

git config --global init.defaultBranch main git config --global core.editor "code --wait" git config --global pull.rebase false git config --global core.autocrlf trueCopy
core.autocrlf true is the recommended Windows setting so line endings stay consistent.

Verify configuration

git config --global --listCopy

4. VS Code Extensions

Recommended ▼

Ensure the code command works

Open VS Code once, then press Ctrl+Shift+P and run Shell Command: Install 'code' command in PATH. After that you can install extensions from the terminal.

code --versionCopy

Python development pack

code --install-extension ms-python.python code --install-extension charliermarsh.ruff code --install-extension ms-toolsai.jupyter code --install-extension ms-python.debugpyCopy
Python Official language support, IntelliSense, debugging
ms-python.python
Ruff Ultra-fast linter + formatter
charliermarsh.ruff
Jupyter Notebook support
ms-toolsai.jupyter

JavaScript / Node.js essentials

code --install-extension dbaeumer.vscode-eslint code --install-extension esbenp.prettier-vscode code --install-extension formulahendry.code-runnerCopy

Git superpowers

code --install-extension eamodio.gitlensCopy

Themes & Icons (pick one or more)

code --install-extension PKief.material-icon-theme code --install-extension zhuangtongfa.material-theme code --install-extension dracula-theme.theme-dracula code --install-extension GitHub.github-vscode-themeCopy

After installing, open VS Code → File → Preferences → Theme → Color Theme and pick your favorite.

5. PATH & Verification

▼

Restart the terminal

Close every open terminal window and open a fresh one. Most winget installers automatically add the tools to PATH.

Verify everything is on PATH

python --version py --version node --version npm --version git --version code --versionCopy
If python or node is not recognized, search for “Environment Variables” in the Start menu, edit the user or system PATH, and add the install directories (usually under %LOCALAPPDATA%\Programs\Python\ and C:\Program Files\nodejs\), then restart the terminal again.
